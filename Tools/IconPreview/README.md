# IconPreview

用于调试菜单栏沙漏图标的小工具。图标代码始终从 `../../SwiftQuit/MenuBarIcon.swift`
编译，所以改了图标后重新构建即可看到最新效果。

## 构建

```bash
./build.sh          # 构建预览 App + 生成静态对照图
./build.sh --open   # 构建后直接打开预览 App
```

产物在 `build/`：

- `build/IconPreview.app`：可交互预览（含 15 秒循环的漏沙动画）
- `build/sheet.png`：静态对照图（浅/深菜单栏、关键状态、全部 17 档）

## 预览内容

1. 菜单栏真实尺寸（18 pt）— 浅色与深色背景
2. 动态演示 — 15 秒从满到空，循环播放
3. 关键状态（56 pt）— 60 分钟 / 45 / 30 / 15 / 0 / 无倒计时 / 暂停
4. 全部 17 档（32 pt）— 默认 60 分钟阈值下每一档对应的分钟数

图标档位数量由 `MenuBarIcon.steps` 决定（当前 16）。
